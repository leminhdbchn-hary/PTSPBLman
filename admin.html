    Chia số lượng quà

    🔑 Để nút “Lưu lên GitHub” chạy (làm một lần)
    1. Vào GitHub → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Repository access: chọn Only select repositories → PTSPBLman. Permissions → Contents: Read and write. Đặt hạn ngắn (ví dụ 7 ngày).
    3. Dán token vào ô dưới. Token chỉ nằm trong trình duyệt của bạn, không gửi đi đâu ngoài GitHub.

    Không muốn dùng token? Bấm Sao chép cấu hình, rồi mở file stock.js trên GitHub → ✏️ → dán đè → Commit.
